# AGENTS.md

Project-specific instructions for coding agents.

## Scope
- Applies to all work in this repository unless overridden by a subdirectory AGENTS.md.

## Coding
- Keep changes minimal and focused.
- Prefer existing patterns and libraries already used in the project.
- Add or update tests when behavior changes (if a test setup exists).

## Tooling
- Use the existing build and lint scripts from package.json when validating changes.

## Communication
- Summarize changes briefly and list any files modified.
- Call out any assumptions or follow-up steps.
